# Nurin Birthday 2026 🎂

A cute interactive birthday website made for Nurin Jazlina Binti Mohamed Azhar.

## Run locally

Make sure Node.js is installed.

```bash
npm install
npm run dev
```

Then open the local URL shown by Vite.

## Build

```bash
npm run build
```

The production files will be in `dist/`.

## Deploy to Vercel

1. Create a GitHub repository.
2. Upload this project to the repository.
3. Go to https://vercel.com/
4. Sign in with GitHub.
5. Import the repository.
6. Vercel should automatically detect the Vite project.
7. Click Deploy.

No environment variables are required.

## Personalization

The main birthday text is in:

`src/main.jsx`

The design is in:

`src/styles.css`

The project intentionally uses CSS decorations rather than external copyrighted images.
